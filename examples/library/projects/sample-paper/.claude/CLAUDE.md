# Paper: Scaling Attention

Authors: Ada Lovelace, Alan Turing. Managed by Lectern — the folder is the source of truth.

## Layout
- `manuscript/index.qmd` — the paper: Quarto YAML (title, authors, formats) plus an
  include block BETWEEN the `lectern:sections` markers that Lectern regenerates from
  the section files — never edit inside the markers; the YAML above them is editable.
- `manuscript/sections/*.qmd` — the manuscript body, one Quarto-markdown file per
  section, ordered by numeric filename prefix. Edit these in place; Lectern renders
  them. Cite as `[@citekey]` against the library bibliography.
- Render the assembled paper with `quarto render manuscript/index.qmd`.
- `../../.lectern/references.bib` — ONE library-wide bibliography GENERATED by Lectern from the
  shared library; every project cites it, so every library paper is available here. Do not hand-edit.
- `.lectern/papers.json` — the library papers foregrounded for this project (the "desk"). This is
  a focus aid only; you can still cite any key in the bibliography, not just these.
- `revisions/revision-plan.md` — the ordered revision plan. Keep status markers in sync.
- `.lectern/todos.json` — granular tasks.

PDFs are not stored in this folder; the `file = {...}` field in the bibliography points at the
shared library location of each PDF.

## House style
- Prefer plain, direct prose. Cut hedging.
- Every empirical claim must cite a key from `references.bib`.
- Never invent citations. If a claim is uncited, flag it — do not fabricate a reference.
- When you complete a revision-plan step, update its checkbox in `revisions/revision-plan.md`.
